# Discord Parser

Локальный инструмент для выгрузки **всех сообщений и авторов** с Discord-сервера
и онлайн-панель для работы с этими данными: прогресс сканирования в реальном
времени, статистика активности, поиск, карточки авторов и экспорт.

![схема](https://img.shields.io/badge/python-3.11%2B-blue) ![fastapi](https://img.shields.io/badge/FastAPI-async-green) ![license](https://img.shields.io/badge/use-personal%20research-lightgrey)

## Возможности

- **Полный обход истории** каналов (текстовые, анонсы, форумы) и веток
  (активные + архивные) с постраничной подгрузкой и обработкой rate-limit Discord.
- **Инкрементальные догоны**: повторный запуск режима `auto` докачивает только новые
  сообщения и продолжает недокачанные каналы.
- **Онлайн-панель**: прогресс по каналам, счётчики собранных/новых сообщений,
  живые обновления через WebSocket, статусы ошибок по каждому каналу.
- **Авторы**: список с числом сообщений, первым/последним сообщением, возрастом
  аккаунта, датой вступления (для ботов с интентом `GUILD_MEMBERS`), карточка
  автора с разбивкой по каналам и последними сообщениями.
- **Поиск** по тексту сообщений и по авторам (включая кириллицу), сортировки,
  пагинация, просмотр вложений и реакций.
- **ZIP-архив итогов**: после парсинга результаты складываются в один zip на
  сервер — внутри папка сервера, в ней папка на каждую категорию и файл на каждый
  канал. Каждое сообщение подписано `[дата время] Автор (@username): текст`
  и отделено `\n`; плюс `_authors.txt` и `_index.txt`.
- **Экспорт** сообщений и авторов в CSV (`;`-разделитель, UTF-8 BOM для Excel)
  и JSON — потоково, без загрузки всей базы в память.
- **Данные хранятся локально** в SQLite (`data/discord_parser.db`), ничего не
  отправляется третьим лицам.

## Установка

```bash
git clone <repo> Discord-Parser && cd Discord-Parser
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
```

Запуск:

```bash
./run.sh                 # http://localhost:8000 (создаст .venv при необходимости)
# или
.venv/bin/python -m uvicorn app.main:app --host 0.0.0.0 --port 8000
```

Переменные окружения:

| Переменная   | По умолчанию              | Назначение                                    |
|--------------|---------------------------|-----------------------------------------------|
| `DISCORD_TOKEN` | —                      | Токен, чтобы не вводить его в панели          |
| `DP_DB_PATH` | `data/discord_parser.db`  | Путь к базе SQLite                            |
| `DP_DATA_DIR`| `data`                    | Каталог данных                                |
| `DP_ARCHIVE_DIR` | `data/archive`        | Куда писать zip-архивы серверов               |
| `HOST`/`PORT`| `0.0.0.0` / `8000`        | Адрес панели (для `run.sh`)                   |

## Токен

Панель работает с двумя типами токенов:

Инструмент работает **только с токеном бота** — пользовательские токены
отклоняются при подключении (панель так и пишет).

1. Откройте `discord.com/developers/applications` → **New Application**.
2. Вкладка **Bot** → **Reset Token** → скопируйте токен.
3. Там же включите **Message Content Intent** (иначе тексты сообщений будут пустыми)
   и при необходимости **Server Members Intent** (дата вступления участников).
4. Пригласите бота на сервер с правами **View Channels** + **Read Message History**.

Токен хранится в памяти процесса. Флажок «Запомнить» сохраняет его в локальную
SQLite-базу, чтобы панель поднималась без повторного ввода.

## Как пользоваться

1. Откройте панель, вставьте токен → **Подключиться**.
2. Выберите сервер в шапке и нажмите **⟳ Синхр.** — подтянутся каналы и ветки.
3. В панели «Сканирование» отметьте каналы и выберите режим:
   - `auto` — догрузить новое и докачать незавершённые каналы;
   - `full` — пересобрать историю выбранных каналов;
   - `rebuild` — удалить данные сервера и собрать заново.
4. Следите за прогрессом: счётчики обновляются через WebSocket, по завершении
   статистика и списки перезагружаются автоматически.
5. Вкладки **Сообщения** и **Авторы** — поиск и карточки; **Экспорт** — CSV/JSON.

### Архив (ZIP)

Вкладка **Архив**:

- итоги каждого парсинга автоматически сохраняются в zip (галочку можно снять);
- кнопка **💾 Сохранить архив** пересобирает zip по текущим настройкам;
- **⤓ Скачать zip** отдаёт готовый файл; слева — дерево содержимого архива,
  справа — предпросмотр любого файла прямо из zip.

Один сервер = один zip на диске: `data/archive/<Сервер>-<id4>.zip`.

```
Demo-server-0001.zip
└── Демо-сервер/                    ← папка сервера
    ├── general.txt                 ← канал без категории
    ├── Текстовые_каналы/           ← папка категории
    │   ├── general.txt             ← файл канала
    │   ├── флудилка.txt
    │   └── dev-chat.txt
    ├── Кухня/
    │   └── мемы.txt
    ├── _authors.txt                ← авторы: сообщений, первое/последнее, id
    └── _index.txt                  ← оглавление архива
```

- категория Discord → папка внутри архива;
- канал → `.txt` файл внутри папки своей категории;
- ветки — в папке категории родительского канала, имя `родитель--ветка.txt`;
- каналы без категории лежат в корне папки сервера;
- голосовые каналы и категории в парсинг не попадают.

Внутри файла канала:

```
# Архив канала #general — Демо-сервер
# файл создан: 26.10.2026 20:48
# сообщений: 281
# формат: [время] Автор (@username): текст; разделитель сообщений: '\n'

[11.09.2026 21:16] Ночная Сова (@nightowl): кто-нибудь понял, почему падает на windows?
[11.09.2026 22:40] Маша (@dev_masha, бот): а есть документация по api? [вложения: photo.png]
```

Настраивается в панели:

| Параметр | Варианты |
|----------|----------|
| формат записи | `строка` (подпись и текст в одной строке) или `блок` (подпись, затем текст) |
| разделитель сообщений | `\n` (по умолчанию), `\n\n`, `---` |
| формат времени | `26.10.2026 19:52`, `2026-10-26 19:52`, с секундами, ISO |
| доп. данные | список вложений, ID сообщения в подписи |

Имя файла канала — это имя канала; ветки сохраняются как
`родитель--ветка.txt`, недопустимые для файловой системы символы заменяются на `_`.

## API

| Метод | Путь | Назначение |
|-------|------|-----------|
| `GET`  | `/api/session` | состояние подключения и список серверов |
| `POST` | `/api/token` | подключиться по токену (`{token, remember}`) |
| `DELETE` | `/api/token` | отключиться |
| `GET`  | `/api/guilds?refresh=true` | серверы аккаунта |
| `POST` | `/api/guilds/{id}/sync` | перечитать каналы сервера |
| `GET`  | `/api/guilds/{id}/channels` | каналы + статус сканирования |
| `POST` | `/api/scan` | запустить сканирование (`guild_id`, `channel_ids`, `mode`, …) |
| `POST` | `/api/scan/stop` | остановить |
| `GET`  | `/api/scan/status` | состояние сканера и прогресс по каналам |
| `GET`  | `/api/stats?guild_id=` | KPI, активность по дням/часам, топы |
| `GET`  | `/api/messages?guild_id=&q=&channel_id=&sort=&limit=&offset=` | выборка сообщений |
| `GET`  | `/api/messages/{id}` | одно сообщение |
| `GET`  | `/api/authors?guild_id=&q=&sort=` | список авторов |
| `GET`  | `/api/authors/{id}?guild_id=` | карточка автора |
| `GET`  | `/api/archive?guild_id=` | zip на диске, дерево содержимого, настройки |
| `POST` | `/api/archive` | собрать zip (`format`, `separator`, `time_format`, …) |
| `POST` | `/api/archive/auto` | включить/выключить автосохранение |
| `GET`  | `/api/archive/entries?guild_id=` | папки категорий и файлы каналов |
| `GET`  | `/api/archive/file?guild_id=&name=` | предпросмотр файла из zip |
| `GET`  | `/api/archive/download?guild_id=` | скачать готовый zip |
| `GET`  | `/api/export/messages?fmt=csv\|json` | потоковый экспорт сообщений |
| `GET`  | `/api/export/authors?fmt=csv\|json` | потоковый экспорт авторов |
| `DELETE` | `/api/guilds/{id}/data` | удалить данные сервера |
| `WS`   | `/ws` | события `scan`, `stats_stale`, `hello` |

## Структура

```
app/
  config.py       настройки и пути
  db.py           схема SQLite, все запросы, экспортные генераторы
  discord_api.py  клиент Discord REST: авторизация, повторы, rate-limit
  scanner.py      движок обхода каналов и веток, состояние прогресса
  archive.py      zip-архив: папки категорий, файлы каналов, формат записей
  main.py         FastAPI: REST + WebSocket + статика
  static/         панель (index.html, style.css, app.js) без сборки
scripts/seed_demo.py  демо-данные для проверки панели
tests/               тесты сканера на фейковом Discord-клиенте
```

## Тесты

```bash
.venv/bin/pip install pytest
.venv/bin/python -m pytest tests -q
```

Покрыто: постраничный сбор, инкрементальный догон, устойчивость к каналам без
доступа (403), режим `rebuild`, остановка на середине, парсинг сообщений;
структура zip «сервер → категории → каналы», формат записей, разделители и
форматы времени, чтение файлов из zip, `_authors.txt`, автосохранение после
сканирования, а также авторизация (бот-токен принимается, пользовательский —
нет).

## Ограничения и правовые заметки

- Инструмент читает **только то, к чему у токена есть доступ**; закрытые каналы
  помечаются ошибкой 403 и не ломают остальной проход.
- Discord отдаёт историю только за время существования канала/ветки; удалённые
  сообщения восстановить нельзя.
- Скорость ограничена rate-limit Discord (панель сама выдерживает паузы), для
  огромных серверов сканирование занимает часы — его можно остановить и продолжить.
- Используйте инструмент только на своих серверах или с разрешения администрации.
  Сбор и хранение переписки людей без согласия может нарушать закон и ToS Discord.
