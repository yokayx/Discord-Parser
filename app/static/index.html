    Готов

    Подключение к Discord

    Нужен токен бота (рекомендуется, с включённым Message Content Intent) или пользовательский токен. Токен хранится только в памяти сервера, если не включено запоминание.

    Как получить токен бота
    1. Откройте discord.com/developers/applications → New Application.
    2. Вкладка Bot → Reset Token → скопируйте токен.
    3. Там же включите Message Content Intent (иначе тексты сообщений будут пустыми).
    4. Пригласите бота на сервер с правами Read Message History и View Channels.
